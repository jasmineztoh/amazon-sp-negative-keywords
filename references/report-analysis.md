# 搜索词报表分析

这是本技能的第二项任务。用户明确要求分析已有 SP 搜索词报表时才运行。内部仍要识别值得新增的否词及不应否定的词；交付的是附有关键数据的**建议否词**，供广告主最终决定，不替广告主执行否定，也不重新制作整套广告优化方案。

## 一、读取与汇总

识别报表来源、站点、币种、广告主类型、日期范围和记录粒度，保留原始行。亚马逊原生导出与第三方工具加工后的同名字段，归因口径未必相同；无法确定时应标记。

按字段含义映射，不按固定列序读取。常见中文列包括：`日期`、`用户搜索词`、`所属广告活动`、`点击量`、`花费`、`广告总订单量`、`广告总销售额`、`直接成交订单量`、`间接成交订单量`、`投放/否定类型`、`匹配类型`、`投放名称`。其他格式可能使用英文列名或缺少部分字段。报表没有广告 ASIN 时，请用户提供映射；活动名称即使含类似 ASIN 的字符串，也不足以证明广告商品身份。

按天报表应在同一站点、币种、广告商品、活动/广告组及完整用户搜索词或商品 ASIN 的范围内汇总。点击、曝光、花费、订单、销售额相加；CPC、CTR、CVR、CPA、ACoS、ROAS 用汇总后的分子分母重算，不能把每日百分比相加或简单平均。不同币种及商品范围不要合并。若用户提供其他活动的数据，要检查同一查询是否在别处成交。**先核对报表广告商品与目标 ASIN 的对应关系**；活动名称里出现另一个 ASIN 时，不得把该活动数据当成目标商品的业绩。映射无法确认时，说明缺口并停在可确认的分析范围，不拼接两款商品的数据。

## 二、识别已有否词和数据异常

先核实报表中否定类型字段的含义。若 `投放/否定类型 = 精准否定` 表示该搜索词已经被精准否定，保留这些行作历史背景，不再计入新增否词。若既有否词与当前商品的核心需求、功能或已成交词存在合理购买路径，内部标为“复核既有否定”，不臆测风险等级；其他已否词标为“已否定”。历史点击不能证明现在的否定设置失效，因为报表没有说明否定生效时间。

核对归因窗口和报表日期口径。当前亚马逊说明中，SP 卖家的购买归因回溯期为 7 天，供应商和图书作者为 14 天；使用前核对最新规则。窗口尚未结束的近期零单，不得定为确定无效。

若某行显示 0 点击、0 花费但有订单或销售额，保留这一成交线索，并标记日期/归因口径待核实。它不能证明该词“零成本出单”，也不能直接用于计算该行转化率。总销售额与直接/间接销售额明显不一致时，先检查字段定义或导出问题。

## 三、先找低绩效完整搜索词，再检查词根

**第一轮：逐条筛选精准否定。** 在每个广告活动内部，按完整用户搜索词汇总多日数据。先找花费高、订单少或零单的词：零单词优先看累计点击、花费和占该活动报表花费的比例；已出单词优先看 ACoS、CPA 与可靠的利润或目标成本。再核对归因成熟度、数据异常、同一活动中的重复记录，以及单复数和近义词的表现。花费占比只能说明报表内预算流向；没有预算受限证据时，不声称它已经挤掉其他词的曝光。

判断依据是**这个完整词在这个广告活动中的表现**，相关性用于解释表现和评估否定范围，不是先挡掉相关词的硬门槛。即使是商品品类词或主要功能词，若在该活动中已有充分成熟的点击和花费却持续零单，也可建议对该完整词`精准否定`。例如广泛投放 mouse 的活动里，完整搜索词 `mouse` 累计 20 多次点击、零订单，且持续消耗明显预算时，可以建议在该活动精准否定 `mouse`，让该活动继续测试其他搜索词；不能因商品本身是 mouse 就排除这条建议。20 次点击是这个场景的证据，不是所有商品的统一自动阈值。若数据很新、报表不完整或已有成交线索，应先核实。

相关词虽已出单，但若成熟数据和可靠利润口径表明它在**该活动**持续亏损，也可列为精准否定建议；不能只凭一次高 ACoS 下结论。某词在其他活动成交，不自动否决当前活动的精准否定建议，但应检查当前活动数据是否被拆散。明确错配词即使点击较少，也可在本轮建议精准否定；这条路径不应取代对高花费低绩效词的排查。已否定的词不重复建议。

**第二轮：从已选精准否词中找词组否定。** 只有多个建议精准否定的完整词含有同一错误意图词根，且检查该活动中含此词根的其他词没有值得保护的成交或合理购买路径时，才另建议词组否定。不要从一条零单词扩展否定整个词根，也不要把商品大词当词组否定词根。词根建议是对已展示精准词的进一步概括，不替代第一轮的完整搜索词和各自数据。没有安全词根就只给精准否定。

原 SOP 用核心词的广告位置决定提价或降价。搜索词报表中的 CTR 不能单独证明广告位置；没有位置数据时，不推断“排得太靠前/靠后”。否词表不输出调价或位置操作。

有可靠利润数据时，用`盈亏平衡 ACoS = 广告前贡献利润率`作为分析参考，并计算`估算广告贡献 = 广告归因销售额 × 广告前贡献利润率 − 广告花费`。广告前贡献利润率应扣除产品、平台、履约等随订单变化的成本；只有笼统“毛利率”时，不能把它直接当成可靠的否词线。估算广告贡献只是归因口径的账面值，不证明增量利润。若销售额包含不同利润率的其他商品且无法确认组合，标为“无法判断”或明确写出假设。缺少利润数据仍可按购物意图和成熟数据筛选，但不能用 ACoS 宣称盈利或亏损；历史受影响花费也不等于未来可节省金额。

按 [表格格式](workbook-schema.md)交付。每条建议都附上用于决定是否否定的投放数据；不要只交付词、匹配方式和原因。已否定、保留和待核实的判断留作内部复核；用户要求完整诊断时再展示。
